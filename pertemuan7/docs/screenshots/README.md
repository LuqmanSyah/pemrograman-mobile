# Tangkapan Layar TabungKu

Simpan tangkapan layar di folder ini dengan nama berkas berikut. Keenamnya wajib menurut modul pertemuan 7 bagian 9, dan sudah dirujuk dari `README.md` proyek.

| No | Berkas | Isi yang harus terlihat |
| --- | --- | --- |
| 1 | `hari-ini.png` | Tab **Hari ini**: kartu ringkasan, progress target, dan daftar kegiatan (pemasukan hijau `+`, pengeluaran merah `-`) |
| 2 | `form-error.png` | **Form kegiatan** setelah menekan Simpan dengan nama kosong dan nominal 0 (pesan kesalahan tampil) |
| 3 | `laporan.png` | Tab **Laporan**: ringkasan, rencana vs realisasi, pengeluaran per kategori, dan 7 hari terakhir |
| 4 | `pengaturan.png` | Tab **Pengaturan**: saklar mode gelap, slider target, dan pilihan warna |
| 5 | `mode-gelap.png` | Halaman mana pun saat **mode gelap** aktif |
| 6 | `tabungan-negatif.png` | Tab **Hari ini** saat pengeluaran lebih besar dari pemasukan (angka merah dan pesan peringatan) |

Tangkapan layar tambahan (opsional): `cari.png` untuk halaman **Cari kegiatan** dengan filter jenis/kategori.
